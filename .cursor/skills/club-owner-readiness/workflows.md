# Club-owner workflow checklist

Copy into the tick notes. Mark each row **works** / **friction** / **missing**.

## Setup

- [ ] Coach can create a **club** or **team** without being offered a district
- [ ] Join link + email/CSV invites work; assistants are read-scoped
- [ ] Settings: rename, state, website, meeting note, ownership transfer
- [ ] Type stays locked (club cannot become a school)

## Finding and going to events

- [ ] Directory search for the club’s type; “My club is going” for signed-in members
- [ ] Coach can mark the club as attending a public event
- [ ] Invite by roster or group; RSVP + “finished organizer registration”
- [ ] Teammates see who else is going (same org, names only)

## Hosting

- [ ] Draft → cover → preview → audience (public / club-or-team only / invite-only — never fake district-only)
- [ ] Public listings wait for Causey review; private is immediate
- [ ] Edit/cancel after publish; calendar .ics exists

## After the event

- [ ] Mark attendance on hosted **and** travel events the club is attending
- [ ] Record division, place, award; blank means not recorded
- [ ] Roster name opens club-scoped history
- [ ] Plan, Family, and Reports show the same outcome language
- [ ] Season CSV includes travel events

## Honesty by type

- Chess: listings exist; USCF ID is typed, not live MSA
- Debate/STEM/arts/writing: hosting works; public indexes are thin or reference-only
- Custom types: public-link only, no directory
